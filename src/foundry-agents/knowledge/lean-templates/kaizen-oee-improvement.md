# Kaizen Event Template: OEE Improvement

## Event Overview

### Pre-Event Planning (1 week before)
- [ ] Define scope: specific line/machine/process
- [ ] Set target: OEE improvement goal (typically 5-15 points)
- [ ] Gather baseline data: 4 weeks of OEE, downtime Pareto, scrap Pareto
- [ ] Assemble team: production operator, maintenance tech, engineer, quality rep
- [ ] Prepare value stream map (current state)

### Event Execution (3-5 days)

#### Day 1: Understand Current State
- Walk the process (Gemba walk)
- Validate baseline data with operators
- Document the Six Big Losses breakdown
- Create current-state OEE waterfall chart

#### Day 2: Identify Root Causes
- For top 3 losses, perform 5-Why analysis
- Create fishbone (Ishikawa) diagrams
- Identify quick wins vs. systemic issues
- Prioritize using Impact/Effort matrix

#### Day 3-4: Implement Improvements
- Execute quick wins immediately
- Develop standard work for key operations
- Implement visual management boards
- Set up autonomous maintenance checklists
- Create/update preventive maintenance tasks

#### Day 5: Validate and Sustain
- Measure post-improvement OEE
- Document new standard procedures
- Set up daily management board
- Assign sustaining ownership
- Schedule 30/60/90 day follow-ups

## Six Big Losses Framework

### Availability Losses
1. **Equipment Failure** (Breakdowns)
   - Unplanned stops > 10 minutes
   - Lean tool: TPM, MTBF/MTTR tracking
   
2. **Setup and Adjustments**
   - Changeovers, warm-up, adjustments
   - Lean tool: SMED (Single Minute Exchange of Die)

### Performance Losses
3. **Idling and Minor Stops**
   - Stops < 10 minutes, jams, blocked sensors
   - Lean tool: Autonomous maintenance, Poka-Yoke
   
4. **Reduced Speed**
   - Running below rated speed
   - Lean tool: Speed loss analysis, constraint identification

### Quality Losses
5. **Process Defects**
   - Scrap and rework during stable production
   - Lean tool: SPC, root cause analysis, Poka-Yoke
   
6. **Startup Losses**
   - Defects during warm-up/startup phase
   - Lean tool: Startup standardization, recipe optimization

## Impact Estimation Formula

```
Annual Impact (hours) = Loss Hours/Year × Expected Reduction %
Annual Impact (€) = Impact Hours × Hourly Production Value
OEE Impact (points) = (Impact Hours / Planned Production Hours) × 100
```

## Sustainability Checklist
- [ ] Standard work documented and posted
- [ ] Training completed for all shifts
- [ ] Visual management board updated daily
- [ ] Escalation procedure defined
- [ ] 30-day audit scheduled
- [ ] KPIs tracked and reviewed weekly
