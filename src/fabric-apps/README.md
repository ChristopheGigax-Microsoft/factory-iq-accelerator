# Fabric Apps

This folder hosts optional Fabric app artifacts for baseline management.

- `src/`: Rayfin workspace app UI and client-side baseline orchestration.
- `rayfin/`: Rayfin project metadata and schema files.

## Bootstrap command

Use the official command from the Rayfin README:

```bash
npm create @microsoft/rayfin@latest
```

## Run

```bash
npm run dev
```
