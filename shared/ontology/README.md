# Factory IQ Ontology Blueprint

This folder contains ontology design artifacts for Fabric IQ / Data Agent integration.

- `factory-iq-ontology-blueprint.yaml`:
  - proposed ISA-95-centric entity model
  - relationship model
  - semantic KPI vocabulary
  - mapping to current SQL + KQL assets in this accelerator

Use this blueprint when creating or refining the Fabric Ontology item in your Fabric workspace.
